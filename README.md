# Packet demo

Clickable front-end prototype of Packet's data unification pilot: onboarding an undocumented hybrid site (60 MW PV + 20 MW / 80 MWh BESS) from first connection to a Canonical Asset Model.

**Prototype with simulated data.** No live systems, no customer data. Nothing is written to any device.

## How to view

Open the GitHub Pages link for this repository. Built for a laptop or projector at 1440 px wide; not designed for phones.

Use **Next** in the header (or the right arrow key) to follow the story in order, or jump between screens from the left nav. **Reset** in the nav footer clears all state.
